# Longitudinal CT Lesion Localization

UT Machine Learning, Fall 2026 course project.

**Task:** given a baseline CT, a follow-up CT of the same patient and the lesion location in the baseline scan, predict the lesion location in the follow-up scan (localisation, not segmentation).
